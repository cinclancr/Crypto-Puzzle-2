# Contributing

Contributions should be in English, cite original footage or primary/public sources, include an experiment identifier, list exact frame indexes and algorithm parameters, and include a falsifiable test or control. Do not publish new undisclosed private-key candidates or third-party copyrighted videos. Include reproducible code, hashes, data provenance and a negative-result record. Use GitHub issues for hypotheses and PRs for verified scripts/docs. A visually convincing pattern is not a confirmed key.
