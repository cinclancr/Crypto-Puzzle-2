# Publication, Data and Responsible Prize-Puzzle Research

- Publish original analysis code, original scientific diagrams, source links, hashes, non-sensitive experiment outcomes and small quotations with attribution.
- The three uploaded MP4 videos and user screenshot are kept in the ZIP's **local_sources** for private research; do not automatically push those files to GitHub. YouTube footage remains copyrighted by its creator. Seek explicit redistribution rights before hosting the full videos or substantial frame libraries publicly.
- **Evidence format policy (2026-11-23):** derived pixel renders (composites, layer masks, window montages, frame crops) are treated as frame-library derivatives and kept OUT of the public tree by default; the published machine-checkable evidence is the JSON reports in `data/evidence/`, which embed ASCII renderings of every glyph composite, the column raster and the six windows, together with geometry and statistics. Anyone with lawful access to the videos can regenerate the PNG renders locally via `scripts/decode_part1_edges.py` and `scripts/decode_part2_column.py`. This can be relaxed only if the channel owner confirms redistribution rights for derived imagery.
- Keep secrets and GitHub credentials out of source, logs and chat. No novel 64-character winning private key should be committed in a public branch, even if a puzzle prize was intended to be public. If verified, notify the repository owner privately; defer any publication or prize action to the owner.
- Read the existing repository's MIT `LICENSE`; it currently includes attribution to `hellnert` (checked Nov 23, 2026). Preserve it unless owner requests a verified legal correction. A GitHub repository URL is not authorization to alter copyright attribution.
- `local_sources/`, raw frames, temp videos, candidate key dumps, `.env`, and derived media caches are excluded by `.gitignore`.
- The goal is scientific reproducibility and evidence-based resolution of a voluntarily public puzzle, NOT exploitation of unrelated wallets/accounts.
